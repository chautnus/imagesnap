## v1.11.10 — Upload speed, Light UI redesign, Data grid/list toggle (2026-06-05)

### Performance

- **Drive folder ID cache** (`src/shared/lib/drive.ts`): 2-tier cache — in-memory `Map` (session) + `localStorage` (24h TTL). Saves 1–2 API round trips per save (~300–600ms). Works across PWA, extension popup, and web.
- **Base64 decode ~10× faster**: Replaced manual `charCodeAt` loop with `fetch(dataUrl).then(r => r.blob())` (native browser API). Eliminates JS-side decode bottleneck for large images.
- **Parallel image upload** (`src/shared/services/productService.ts`): Replaced sequential `for` loop with `Promise.all`. 3 images: latency drops from 3× to ~1× upload time.
- **setPermission fire-and-forget**: Drive permissions request no longer awaited — sent in background, unblocking `webViewLink` return immediately.

**Benchmark (typical 3-image save, 1MB/img):**
| Before | After |
|--------|-------|
| ~9–10s | ~2–3s |

### UI Redesign — Light Mode

New design token palette (`src/web/index.css`):

| Token | Old (dark) | New (light) |
|-------|-----------|-------------|
| `--color-bg` | `#0a0a0c` | `#F0F4FF` |
| `--color-card` | `#121217` | `#FFFFFF` |
| `--color-accent` | `#0078d7` (Windows blue) | `#4F6EF7` (indigo) |
| `--color-line` | `#1f1f27` | `#E2E8F0` |
| `--color-muted` | `#a1a1aa` | `#94A3B8` |

Component changes:
- **`label-meta`**: 18px mono bold CAPS → 11px semibold uppercase (lighter, faster to scan)
- **`.input`**: Dark bg → white bg, soft focus ring `ring-2 ring-accent/20`
- **`.btn-primary`**: Brutalist `4px solid black shadow` → `rounded-xl shadow-sm shadow-accent/30`
- **`.card`**: Dark card → white + `shadow-sm`

**Navigation** (`src/web/components/Navigation.tsx`): ALL CAPS 10px → capitalize 11px semibold; active icon uses `strokeWidth 2.5` vs `1.8` for inactive; pill active state retained.

**Header** (`src/web/components/Header.tsx`): Simplified layout; sync indicator uses emerald dot with glow; Pro badge uses amber color; `isSyncing` shows animated `RefreshCw` icon.

### Features

- **Data tab grid/list toggle**: New `LayoutGrid` / `List` button in `DataTab.tsx` items and search views. State persists to `localStorage` key `data_layout`. Grid layout: 2-column, square image aspect ratio.

### Refactor — DataTab split (597 → 198 lines)

Per SYSTEM LOCK rule (>250 lines), `DataTab.tsx` was split:

| New file | Lines | Responsibility |
|----------|-------|---------------|
| `DataSearchBar.tsx` | 90 | Search input + filter panel (was copy-pasted 3×) |
| `DataProductCard.tsx` | 107 | Product card with `layout: 'list' \| 'grid'` prop |
| `DataProductDetail.tsx` | 73 | Full-screen product detail view |
| `DataTab.tsx` (retained) | 198 | State orchestration + navigation views |

No downstream import changes required — `AppDashboard.tsx` only imports `DataTab`.
