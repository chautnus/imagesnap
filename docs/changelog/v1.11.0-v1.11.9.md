## v1.11.0 — Official production stable (2026-05-16→17)

- **Staff portal GA**: Staff login, directory, and admin routes promoted to stable.
- **Debug overlay**: Logging overlay restricted to `chautnus@gmail.com` only — hidden from all other users.
- **Cleanup**: Removed all dev logs, debug overlays, and yellow border artifact in Settings.

---

## v1.11.1 — Capture & DB migration fixes

### Fixed
- **Staff DB migration**: Schema migration runs safely on first boot without crashing existing tables.
- **Reactive routing**: Dashboard navigation now reacts to route changes without full-page reload.
- **Search suggestions**: Resilient fetch — no longer crashes on network error; falls back to empty list gracefully.
- **Capture UI**: Updated help guide, cleaned top-guide clutter from CaptureTab, balanced capture actions grid, and fixed usage counter API call.

---

## v1.11.2 — Staff directory & login hardening

### Fixed
- **Staff directory alerts**: Suppressed noisy browser alerts on directory load errors.
- **Case-insensitive login**: Staff email matching is now case-insensitive.
- **`userEmail` mapping**: Corrected field name mismatch in staff session payload.

---

## v1.11.3 — Staff API error safety

### Fixed
- **Staff API response parsing**: Safely reads `text()` before attempting `json()` on error responses — prevents crash when server returns HTML error page instead of JSON.

---

## v1.11.4 → v1.11.5 — PostgreSQL & dotenv stabilization

### Fixed (v1.11.5)
- **PostgreSQL keyword conflicts**: Quoted reserved-word column names in SQL queries.
- **`jsonb` type casting**: Explicit `::jsonb` casts added to prevent type mismatch on Neon.
- **Isolated staff API**: `/api/staff/*` routes use their own DB connection pool, preventing cross-contamination.
- **dotenv diagnostics**: Added local vs online `.env` load diagnostics to `/api/health` endpoint.

---

## v1.11.6 — Multi-variable DATABASE_URL resolution

### Fixed
- **BOM scrubbing**: Strips UTF-8 BOM from `.env` values read at runtime.
- **Absolute path dotenv loading**: Uses `path.resolve(__dirname)` to load `.env` — avoids CWD ambiguity on Railway/Vercel.
- **Forced-dynamic routes**: Staff and auth routes marked `export const dynamic = 'force-dynamic'` to prevent Next.js static-build caching of DB calls.
- **Multi-variable resolution**: Falls back through `DATABASE_URL`, `POSTGRES_URL`, `ImageSnap_DATABASE_URL` in order.

---

## v1.11.7 — Turbopack / Webpack env injection fix

### Fixed
- **`DATABASE_URL` build-time replacement**: Bracket notation (`process.env['DATABASE_URL']`) prevents Webpack/Turbopack static string replacement at build time.
- **`import.meta.url` CWD issues**: Replaced `import.meta.url`-based path resolution with `process.cwd()` for Node.js compatibility.
- **dotenvx conflict removal**: Removed `dotenvx` loader that conflicted with Next.js built-in env handling.

---

## v1.11.8 — Extension CWS sync & PWA routing overhaul

### Fixed
- **Extension ↔ Web sync**: Extension rebuilt against latest web auth flow — login, token revoke, and session endpoints aligned.
- **`revokeToken` relative URL**: Fixed absolute URL hardcode that broke token revocation in extension context.
- **Staff login hidden in extension**: Staff login button removed from extension popup (CWS privacy policy compliance).
- **CWS privacy violation**: Removed data fields collected but not declared in Chrome Web Store privacy form.
- **Hash-based navigation removed**: All `/#staff`, `/#dashboard`, `/#settings` hash routes replaced with proper Next.js file-based routes (`/staff`, `/dashboard`, `/settings`).
- **Staff route redirect**: Staff login button now navigates to `/staff` route instead of hash anchor.
- **Android back button trap**: `popstate` listener added to dashboard — pressing Android back button no longer navigates back to Google OAuth screen.

### SEO (Round 2 audit)
- Fixed canonical tag gaps on all dynamic routes.
- Added `noindex` to private/authenticated pages (`/dashboard`, `/settings`, `/staff`).
- Added SSR rendering for `/features` and `/integrations` pages.
- Completed round-2 SEO audit across all web pages.

---

## v1.11.9 — PWA session persistence (2026-05-28)

### Fixed
- **Token persistence across browser restart**: Google OAuth token now saved to both `localStorage` AND a secure HTTP-only cookie as backup.
- **Session restore on token expiry**: When Google token is expired/missing on page load, app reads session cookie to restore authenticated state — prevents unnecessary re-login.
- **SSR build errors**: Resolved `window is not defined` and `localStorage` access errors during Next.js server-side rendering.

---

## Post-v1.11.9 patches (2026-05-28)

### Fixed
- **SEO pricing correction**: Pricing updated from `$19` → `$9.99` across all marketing pages.
- **Dynamic OG images**: `/api/og` endpoint now generates dynamic Open Graph images per page.
- **`robots.txt`**: Added `Disallow` rules for private routes; corrected sitemap URL.
- **Homepage metadata**: Title, description, and canonical updated for homepage SEO.
- **Privacy page**: Restored missing `BackButton` component; removed deleted `PrivacyClient` import.
- **Mojibake fix (15 files)**: Emoji and special characters (`—`, `▾`, `👁️`, `🧠`, `❌`) were double-encoded (UTF-8 bytes misread as Windows-1252 then re-encoded). Fixed by decode UTF-8 → re-encode as Windows-1252 → decode as UTF-8, saved as clean UTF-8 without BOM. Affected: use-cases, alternatives, compare, blog, features pages.
